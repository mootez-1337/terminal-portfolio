> **Qiangwang Mimic Defense 2026 Quals · Crypto · easy · 380 pts**

## Summary

The handout is a bare Learning-With-Errors (LWE) instance (`q`, `A`, `b`)
plus a masked ciphertext. The error is small enough to recover with a single
LLL reduction via Kannan's embedding; once the error is known, the secret
drops out of plain linear algebra over `GF(q)` and turns out to be a binary
vector, which is the seed for the masking key.

## Solution

### Step 1: Recover the error vector with a lattice reduction

The handout gives `q=7681`, `n=32`, `m=64`, a `64×32` matrix `A`, a length-64
vector `b = A·s + e (mod q)`, and a 28-byte `masked_update` hex blob.

Build the q-ary lattice generated by `q·I_m` and the columns of `A`, embed
the target `b` with a Kannan tag coordinate, and run LLL. With `m=64`
samples against an `n=32` secret the error is heavily overdetermined, so a
single LLL pass (no BKZ needed) finds `(e, ±1)` as the shortest vector —
confirmed by its tiny norm² (42) and every entry of `e` landing in
`{-1, 0, 1}`.

With `e` known, `A·s ≡ b − e (mod q)` is a plain linear system; Gaussian
elimination over `GF(7681)` recovers `s` directly, verified by
`max|error| = 1` across all 64 samples. `s` turns out to be purely binary
(`{0,1}^32`) — the "seed from dropout" hint in the flag.

### Step 2: Derive the mask and recover the flag

The masking key is `SHA256` of the secret serialized as 32 raw 0/1 bytes;
XOR its first 28 bytes with `masked_update` to get the flag.

```python
#!/usr/bin/env python3
"""samples.zip LWE solver — handout -> flag."""
import json, hashlib
from fpylll import IntegerMatrix, LLL

d = json.load(open("samples.json"))
q, n, m = d["q"], d["n"], d["m"]
A, b = d["A"], d["b"]

# --- Kannan embedding: find (e, 1) as a short vector of the q-ary lattice ---
t = 1
M = IntegerMatrix(m + n + 1, m + 1)
r = 0
for i in range(m):
    M[r, i] = q; r += 1
for j in range(n):
    for i in range(m):
        M[r, i] = A[i][j]
    r += 1
for i in range(m):
    M[r, i] = b[i]
M[r, m] = t

LLL.reduction(M)

cand = None
for i in range(M.nrows):
    row = [M[i, j] for j in range(m + 1)]
    if row[m] in (1, -1):
        nn = sum(x * x for x in row[:m])
        if cand is None or nn < cand[0]:
            cand = (nn, row[:m], row[m])
_, w, tag = cand
e = w if tag == 1 else [-x for x in w]        # e = b - A s (mod q)

# --- solve A s = b - e (mod q) over GF(q) ---
def solve_modq(A, rhs, n, q):
    aug = [A[i][:] + [rhs[i]] for i in range(len(A))]
    pr = 0
    piv = []
    for c in range(n):
        sel = next((rr for rr in range(pr, len(aug)) if aug[rr][c] % q), None)
        if sel is None:
            continue
        aug[pr], aug[sel] = aug[sel], aug[pr]
        inv = pow(aug[pr][c], -1, q)
        aug[pr] = [(x * inv) % q for x in aug[pr]]
        for rr in range(len(aug)):
            if rr != pr and aug[rr][c] % q:
                f = aug[rr][c]
                aug[rr] = [(aug[rr][k] - f * aug[pr][k]) % q for k in range(n + 1)]
        piv.append((pr, c)); pr += 1
        if pr == n:
            break
    s = [0] * n
    for ri, c in piv:
        s[c] = aug[ri][n] % q
    return s

rhs = [(b[i] - e[i]) % q for i in range(m)]
s = solve_modq(A, rhs, n, q)

# sanity check: s should be binary, error should be tiny
assert all(x in (0, 1) for x in s)

# --- unmask ---
mask = hashlib.sha256(bytes(s)).digest()
masked = bytes.fromhex(d["masked_update"])
flag = bytes(a ^ b for a, b in zip(masked, mask))
print(flag.decode())
```

dependency on some platforms). Output:
